VOTRE APPAREIL · VOS CONNEXIONS

Prêt à observer le marché ?

Une seule installation. Connectez votre compte ChatGPT, puis préparez la simulation. Les connexions sont conservées sur ce PC.

01

ChatGPT

Le navigateur officiel s’ouvre. Choisissez votre compte et autorisez l’utilisation de votre forfait, si votre compte est éligible.

Compte non connecté

Modèle GPT choisi automatiquement

Plus/Pro éligible et autorisation nécessaires. Une limite du forfait met les nouvelles entrées en pause. La connexion ne donne pas accès à vos conversations.

02

MEXC LECTURE + TRADING

Créez une clé dédiée avec lecture du compte, lecture des ordres et envoi d’ordres. Le bot utilisera uniquement les marchés accessibles avec cette clé.

Compte non connecté

Ajouter les permissions Futures

La lecture Futures nécessite les permissions adaptées et, selon MEXC, la vérification d’identité du compte.

N’autorisez pas l’envoi de retraits ni de transferts. La lecture des informations de monnaies est utilisée pour FOMOAPI. Les permissions de la clé sont vérifiées par l’API. Les clés ne sont jamais envoyées à GPT ni publiées sur GitHub.

03

FOMOAPI OPTIONNEL · SIGNAUX DE TRADERS

Ajoutez votre clé pour recevoir les achats et ventes des traders FOMO. GPT évalue les signaux et leurs classements ; vous n’avez pas de trader à sélectionner.

Flux non connecté

La clé est chiffrée sur ce PC. FOMOAPI fournit les données ; les ordres restent sur MEXC. Le forfait gratuit annonce 7 jours de temps réel, puis 15 secondes de retard. Le délai réellement annoncé par le flux s’affiche ici.

Pour identifier les tokens, la clé Spot MEXC doit aussi avoir la permission de lecture des informations de monnaies : SPOT_WITHDRAW_READ. Cela n’autorise pas de retrait. N’activez jamais SPOT_WITHDRAW_WRITE ni les transferts. Un token sans correspondance réseau + contrat est écarté.

Ce connecteur utilise le flux de l’application FOMO ; il ne garantit pas chaque transaction du trader. Une vente reçue ferme entièrement la position copiée correspondante, même en mode OFF.

04

Un montant, puis ON

Le montant se règle sur le tableau de bord. GPT choisit les marchés, les montants et les leviers parmi ceux autorisés par votre compte. Le capital est partagé entre les positions.

Les sept premiers jours de données disponibles sont une observation sans ordre réel. Tant que ON reste actif, le moteur passe ensuite au réel automatiquement, avec le capital initial et les permissions vérifiées. Les résultats fictifs ne deviennent jamais du capital réel.

OFF bloque les nouvelles entrées ; le suivi et les sorties des positions existantes continuent. Les stops Spot sont locaux : gardez ce PC et l’application ouverts. Futures utilise la marge isolée et des stops/TP envoyés à MEXC.

FOMOAPI se connecte automatiquement après enregistrement de la clé. Ce fichier JSONL reste une option avancée pour une autre source. FOMOAPI est indépendant de CopyFOMO ; les analyses autonomes et Momentum continuent sans ce flux.

GUIDE INTÉGRÉ

Connecter et démarrer

  1. Ouvrir Maxibot 2.0

    Installez le fichier Setup.exe de la release GitHub ou ouvrez la version Portable.exe. Node.js et les bibliothèques sont inclus.

  2. Connecter ChatGPT dans votre navigateur

    Cliquez sur « Continue with ChatGPT ». Identifiez-vous sur le site officiel OpenAI, choisissez le compte ou l’espace de travail et accordez l’autorisation de forfait. Revenez dans Maxibot 2.0 : le modèle GPT est choisi automatiquement. Si le forfait n’est pas éligible ou si la limite est atteinte, l’application l’indique.

  3. Préparer MEXC si vous souhaitez connecter votre compte

    Dans MEXC, ouvrez votre profil puis la gestion API. Créez une clé dédiée à Maxibot 2.0 avec lecture du compte, lecture des ordres et envoi d’ordres. Conservez Access Key et Secret Key, affichée une seule fois. Désactivez les droits d’envoi de retraits et de transferts. Collez les deux valeurs directement dans Maxibot 2.0 puis cliquez sur « Tester et enregistrer ». Pour Futures, configurez lecture et envoi d’ordres ainsi que la lecture Spot du compte pour vérifier son identité. Si vous utilisez une restriction IP, elle doit correspondre à l’adresse publique de votre PC.

  4. Ajouter FOMOAPI pour suivre les traders

    Créez une clé sur fomoapi.io/dashboard avec votre email, puis collez-la dans le champ FOMOAPI de Connexions et cliquez « Tester et connecter ». Le flux et ses délais sont affichés. Ajoutez à la clé Spot MEXC la lecture SPOT_WITHDRAW_READ pour vérifier les contrats des tokens ; cela ne doit jamais inclure SPOT_WITHDRAW_WRITE. GPT choisira les signaux à suivre dans le budget commun. Le flux de l’application peut omettre certaines transactions ; ce suivi ne constitue pas une copie intégrale garantie.

  5. Lancer la simulation

    Indiquez le montant total alloué en USDT puis cliquez ON. Le bot observe pendant sept jours de couverture, puis peut envoyer des ordres réels automatiquement tant que ON est actif. OFF suspend les nouvelles entrées.

  6. Garder le PC disponible et lire le rapport

    Réduire la fenêtre laisse l’application fonctionner. Fermer Maxibot 2.0 ou éteindre le PC arrête le travail. Le journal est conservé à la reprise, mais la période d’observation compte seulement les périodes avec données. Exportez le rapport pour évaluer les résultats et les périodes sans données.
